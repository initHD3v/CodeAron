# Test Generation Skill

Skill ini membuat unit tests yang comprehensive dan maintainable.

## Step 1: Analyze Code

Pahami code yang akan di-test:

1. **Baca source file** dengan `file_read`
2. **Identifikasi**:
   - Functions/methods yang perlu di-test
   - Input parameters dan types
   - Return values dan edge cases
   - Dependencies dan side effects
   - Error handling

3. **Cari existing tests** dengan `glob` pattern `test_*.py` atau `*.test.js`
   - Ikuti testing conventions yang sudah ada
   - Lihat testing framework yang digunakan (pytest, unittest, jest, dll)

## Step 2: Design Test Strategy

### Test Categories

1. **Happy Path** - Normal usage scenarios
2. **Edge Cases** - Boundary conditions, empty inputs, max values
3. **Error Cases** - Invalid inputs, exceptions
4. **Integration** - Interactions with dependencies

### Test Structure (AAA Pattern)

```python
def test_something():
    # Arrange - Setup test data
    input_data = ...
    expected = ...
    
    # Act - Execute code under test
    result = function_under_test(input_data)
    
    # Assert - Verify results
    assert result == expected
```

## Step 3: Generate Tests

### Untuk Setiap Function/Method:

1. **Test nama yang deskriptif**
   ```python
   def test_parse_valid_json_returns_dict():
   def test_parse_invalid_json_raises_error():
   ```

2. **Cover edge cases**:
   - Empty/null inputs
   - Maximum/minimum values
   - Special characters
   - Unicode
   - Very large inputs

3. **Test error handling**:
   ```python
   def test_divide_by_zero_raises_exception():
       with pytest.raises(ZeroDivisionError):
           divide(10, 0)
   ```

4. **Mock external dependencies**:
   ```python
   @patch('module.external_api')
   def test_with_mock(mock_api):
       mock_api.return_value = {...}
       # test logic
   ```

## Step 4: Quality Checklist

Pastikan tests:

- [ ] **Independent** - Tidak depend on test lain
- [ ] **Repeatable** - Same result every time
- [ ] **Fast** - Unit tests harus < 100ms each
- [ ] **Isolated** - No external dependencies (use mocks)
- [ ] **Descriptive names** - Nama test menjelaskan apa yang di-test
- [ ] **One assertion per concept** - Jangan test terlalu banyak dalam 1 test

## Step 5: Write Test File

Simpan test file dengan konvensi project:
- Python: `test_<module>.py` atau `<module>_test.py`
- JavaScript: `<module>.test.js` atau `test/<module>.js`

Include di awal file:
```python
"""
Unit tests for <module>
Generated by CodeAron Test Skill
"""
```
